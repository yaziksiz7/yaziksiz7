### [🔊 Decibel Noise Measurement Device](https://github.com/yaziksiz7/decibel-meter-msp430)
A real-time sound level meter built on an MSP430: reads a microphone sensor, calculates the decibel level and shows it on an I2C LCD. Measurement data is streamed over UART. Schematic and PCB designed in KiCad.

`MSP430` `C` `I2C LCD` `UART` `KiCad`

</td>
